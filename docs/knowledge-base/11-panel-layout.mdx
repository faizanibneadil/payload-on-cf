# Panel layout

Source of truth: `src/components/playground/PanelWorkspace.tsx`. All diagrams below are plain text.

## Panels (left to right)

```text
+----------+----------+------------------+------------------+
|  Theory  |  Files   |      Code        |     Preview      |
| 280-720  | 180-420  |   min 360        |   min 320        |
| default  | default  |   no max         |   no max         |
|   360    |   240    |                  |                  |
+----------+----------+------------------+------------------+
```

Sizes are in px. Code and Preview have no max and the layout is not locked to a container or max-width.

## Open and closed states

```text
OPEN (horizontal)                       CLOSED (rail, 40px)
+--------------------------+            +----+
| FILES        [+][+][<]   |            | [] |
|--------------------------|            | F  |
| index.html               |            | I  |
| script.js                |            | L  |
| styles.css               |            | E  |
+--------------------------+            | S  |
                                        +----+
```

- Clicking a rail opens the panel. The collapse button in a panel header closes it.
- Dragging a separator below the panel's min size collapses it to its rail.
- The header has no Theory button; Theory is opened from its rail.

## Initial state

```text
Wide screen (>= 1280px)      Narrower screens
all four panels open         Theory closed (rail)
                             Files, Code, Preview open
```

## Auto-close when space runs short

```text
1. Open a panel (or shrink the window)
2. Do the open panels still fit their min sizes?
      yes -> done
      no  -> close the oldest-opened panel that is not protected
3. Repeat until it fits
```

Rules:
- Code never auto-closes.
- At least one of Code and Preview always stays open (the other one's collapse button is disabled).
- Panels are evicted least recently opened first, so Files usually goes before Preview.

## Mobile (below 768px)

```text
+------------------------------+
| title bar                    |
|------------------------------|
|                              |
|  one panel at a time         |
|                              |
|------------------------------|
| Theory | Files | Code | Prev |
+------------------------------+
```

Bottom tabs switch between Theory, Files, Code and Preview. Panels are mounted on first visit and then kept alive.

# Preview tabs

```text
+--------------------------------------------+
| [index.html x] [about.html x] [+]   [>]    |  tab strip, max 10 tabs
|--------------------------------------------|
| (R) localhost /index.html                  |  per-tab address bar + refresh
|--------------------------------------------|
|              sandboxed iframe              |
|--------------------------------------------|
| CONSOLE                              [clr] |  per-tab console
+--------------------------------------------+
```

- Every tab keeps its own iframe, address bar, refresh and console, and stays mounted while hidden.
- The `+` button is disabled at 10 tabs ("Maximum 10 preview tabs"). The last remaining tab cannot be closed.
- On mobile the tab strip becomes a dropdown (tab list, New tab, Close this tab).

# Theory editor toolbar

```text
Select text            ->  [B I U S link | H1 H2 H3 quote]   (bubble toolbar)
Type "/" on empty line ->  Bullet list / Numbered list / Code block / Table / Divider
Cursor inside a table  ->  [+ Row] [+ Column] [delete table]
Read-only viewer       ->  no toolbar, no slash menu
```

There is no fixed toolbar. Files: `src/components/playground/theory/bubble-toolbar.tsx` and `slash-menu.tsx`.
